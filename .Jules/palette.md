## 2026-09-01 - Enhance Keyboard Shortcuts Accessibility
**Learning:** While tooltips (via the `title` attribute) can hint at keyboard shortcuts visually, screen reader accessibility specifically requires the semantic `aria-keyshortcuts` attribute mapping to correct standardized modifiers (e.g., `Control`, `Meta`) and key names (e.g., `Delete`, `Backspace`).
**Action:** When adding or maintaining interactive actions that leverage keyboard shortcuts (e.g., Undo, Copy, Paste, Delete), always ensure `aria-keyshortcuts` attributes align with the specific event handling logic attached in JavaScript to expose accurate shortcut patterns.
