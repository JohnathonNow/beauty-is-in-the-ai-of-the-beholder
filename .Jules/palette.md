## 2023-10-27 - Discoverability and Accessibility of Modal Cancellations
**Learning:** Progressive disclosure forms and dynamically displayed sections (like the lobby creation view) need implicit and explicit escape routes. While a visual "Cancel" button is good, adding standard keyboard shortcuts (like `Escape`) and making them discoverable via `title` tooltips and `aria-keyshortcuts` drastically improves usability for power users and accessibility for screen reader users. Furthermore, global `keydown` listeners for such shortcuts must be carefully scoped (e.g., verifying the container's visibility) and usually should bypass standard input/textarea filtering so users can dismiss the modal even when an input is focused.
**Action:** When implementing modal-like views, always pair them with an explicit 'Cancel' button. Map the standard 'Escape' key to trigger this cancellation, ensure the shortcut is documented in the button's `title` and `aria-keyshortcuts` attributes, and ensure the global event listener bypasses input focus checks while verifying modal visibility.
